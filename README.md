# Artie Spiegel

An AI-orchestrated screenwriting studio. The system interrogates, diagnoses,
and visualizes. The writer writes.

## Stack

- Google Gemini via ADK
- ClickHouse (analytical layer)
- Confluent Cloud (event stream)
- Supabase / Postgres (transactional)

## Setup

See `.env.example` for required configuration.

    ./setup.sh
